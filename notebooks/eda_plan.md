# EDA Plan

## Purpose

This file defines exploratory analysis goals for MovieLens data.

## Questions

| Question | Purpose |
|---|---|
| How many users exist? | Understand user scale |
| How many movies exist? | Understand catalog scale |
| What is the rating distribution? | Understand target behavior |
| Which movies have the most ratings? | Understand popularity bias |
| Which genres are most common? | Understand catalog mix |
| How sparse is the user movie matrix? | Understand recommender difficulty |

## Planned Outputs

- Rating distribution chart
- Top rated movies table
- Most rated movies table
- Genre distribution table
- User activity summary
- Movie activity summary
