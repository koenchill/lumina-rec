# Portfolio Summary

## Project

Lumina Rec

## Category

MLOps, recommender systems, API security, local cloud style architecture.

## Summary

Lumina Rec is a local recommendation platform that demonstrates model training, model tracking, artifact storage, secure inference, observability, testing, and governance.

## Technology Stack

| Layer | Technology |
|---|---|
| Model training | PyTorch |
| Experiment tracking | MLflow |
| Artifact storage | MinIO |
| Metadata store | Postgres |
| API | FastAPI |
| Containers | Docker Compose |
| Tests | Pytest |
| Load testing | Locust |
| Metrics | Prometheus client |

## Portfolio Value

This project shows practical skill in:

- MLOps architecture
- Model artifact governance
- API design
- Secure model serving
- Docker based local deployment
- Automated validation
- Operational documentation
