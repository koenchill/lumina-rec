# Success Criteria

## Purpose

This file defines what success looks like for Lumina Rec.

## Local Success Criteria

| Criteria | Status Target |
|---|---|
| Docker Compose stack starts | Required |
| MLflow is reachable | Required |
| MinIO bucket exists | Required |
| Inference service becomes ready | Required |
| `/predict` works | Required |
| `/recommend` works | Required |
| `/movies/{movie_id}` works | Required |
| Model checksum validation is enabled | Required |
| API tests pass | Required |
| Git status is clean after commit | Required |
