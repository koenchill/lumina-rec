# Non Goals

## Purpose

This file defines what Lumina Rec is not trying to solve right now.

## Current Non Goals

| Non Goal | Reason |
|---|---|
| Production deployment | Local structure is being completed first |
| Real customer personalization | Dataset is public MovieLens |
| Regulated decision making | Project is for recommendation practice only |
| Full identity platform | API key is sufficient for local development |
| Real time feature serving | Feature store is planned later |
| Advanced ranking model | Baseline matrix factorization comes first |
| Full UI application | API and MLOps backend come first |
| Cloud infrastructure deployment | Local Docker/K8s/Terraform only; no cloud accounts provisioned |
| Enterprise monitoring | Local metrics and logs come first |
